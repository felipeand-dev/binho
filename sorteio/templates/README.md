# templates/ (globais)

- `base.html` — layout comum (tema escuro do palco): cabeçalho, toasts, modal de
  confirmação, bibliotecas via CDN e `static/css/estilo.css` + `static/js/app.js`.
- `partials/` — `_toasts.html` e `_modal_confirmacao.html`.

A tela do sorteio fica no app: `sorteios/templates/sorteios/palco.html`.
